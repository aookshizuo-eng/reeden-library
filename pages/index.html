Cloudflare R2

一个私有 Bucket 存放主题文件、预览图、字体和库清单；普通主题可在设备本地压缩，加密主题会先生成明文图片预览；电脑本机后台可压缩重封，手机/静态网页会保留原包并显示提示。预览优先组合日间书架，有同模式启动图时一起展示，日间无可用资源才读取夜间。文件使用临时下载地址，Bucket 无需公开。

打开 Cloudflare R2 控制台

查看 R2 访问密钥说明

后台任务正在使用当前存储位置，完成后可修改配置。

在 Cloudflare 控制台按 Ctrl + K，搜索 Copy account ID 并复制。查看查找位置

R2 控制台 → Overview，复制已有存储桶的名称。

普通 Bucket 留空即可，由 Account ID 自动生成。也可从 R2 Overview 或创建密钥完成页底部复制 S3 API 地址；特殊区域使用控制台给出的地址。

由你指定的库文件夹，默认 reeden-library。读取已有文件时填它们所在目录；若文件在 Bucket 根目录，留空。

R2 Overview → API Tokens 旁的 Manage → 创建 Account 或 User API token。权限选 Object Read & Write，仅授权此 Bucket；创建完成后分别复制 Access Key ID 和 Secret Access Key。Secret 只显示一次，丢失需创建新密钥。这里填写 R2 的 S3 密钥对，不填普通 Cloudflare API Token。密钥仅提交到本机后端，并由 Windows 当前用户加密保存；已有凭据时留空可保留。
