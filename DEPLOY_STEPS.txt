# Free deployment helper (does not contain credentials)
# The production site is Cloudflare Pages Direct Upload (project red-garden-sync,
# production branch main). Android APK loads the GitHub Pages copy from the
# same source tree, so both must be published after a UI change.

# Mandatory before every publish:
# 1. node scripts/sync-pages.mjs
# 2. node scripts/verify-pages.mjs --cloudflare
# 3. node worker/test-worker.mjs
# 4. node worker/test-private-repack.mjs
# Optional online sampling (reads a library index page and up to 3 previews):
# node scripts/verify-pages.mjs --url=https://red-garden-sync.pages.dev --preview-limit=3 --skip-download-probe

# Deploy Cloudflare Pages (Wrangler OAuth login is stored on the local machine):
# npx wrangler@4 login
# npm ci
# npm run build:pages
# npm run verify -- --cloudflare
# npx wrangler@4 pages deploy dist-pages --project-name=red-garden-sync --branch=main
# Production secrets (never commit):
# npx wrangler@4 pages secret put SYNC_WRITE_TOKEN
# npx wrangler@4 pages secret put REEDEN_PRIVATE_FORMAT_KEY_B64
# Changing a secret requires a new `pages deploy` before it takes effect.

# Publish GitHub Pages / APK frontend:
# git push origin main    (runs Publish Red Garden Pages + Build Red Garden Android APK)
# If the proxy fails, retry with:
# git -c http.sslBackend=openssl -c http.version=HTTP/1.1 push origin main

# Final acceptance:
# node scripts/verify-pages.mjs --url=https://red-garden-sync.pages.dev --require-current --preview-limit=3 --skip-download-probe
# (omit --skip-download-probe only when testing the streamed ZIP download route)
# plus a real-browser DOM check of #fonts and #themes.

# Server/CLI upload into the same Worker + R2 (token from the environment only):
# REEDEN_SYNC_TOKEN=<token> node scripts/remote-import.mjs --dir <folder>
# Optional original-RED backup: add --123-token <session> --123-folder <dir>
